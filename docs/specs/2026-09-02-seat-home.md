# Seat `home` + catalog env + `/lib/oath`

Amends T9 (root was the only Unix principal) and T16 (root-only SSH).
Folds the `/usr` tree into `/lib/oath` (amends T14’s helper path).
Enforces T30: Grok cannot replace `pkg:grok` without going through
`oath`. Extends `host:local`. No new kind.

## Locks this freeze owns

- **Unix name `home`.** uid/gid **1**. The userland peer of `root`
  (0). Not 1000. Not a `daemon` account — we do not have one.
  Not `user`. No `user` kind. No username field on `host:local`.
- **`HOME=/home`.** The directory itself, not `/home/home`. Grok
  state is `/home/.grok`. passwd/group/shadow are pack + boot side
  effects, like `/etc/hostname`.
- **Graphical stack runs as `home`.** `svc:river` and `svc:sola-*`
  (bus, call, river bridge, shell, session). Audio daemons
  (`svc:pipewire` / `wireplumber` / `pipewire-pulse`) are the same
  seat. PID 1, `svc:serial`, `svc:hold`, `svc:sshd`, `svc:seatd` stay
  root. `/etc/group` is `root` and `home` only — no
  `wheel`/`video`/`input`/`seat`. DRM, evdev, and `/dev/snd` are
  `0660` root:`home`; seatd `-g home`. `/oath/log` is writable by the
  seat (sticky).
- **SSH is `home` only.** `ssh:local` keys land in
  `/home/.ssh/authorized_keys`. Dropbear `-w` (no root login).
  Password auth stays off. **Serial stays root** (break-glass).
  Installer ramdisk SSH stays root (that environment is not the
  installed seat).
- **`home` may `sudo` anything, no password.** `/bin/sudo` is a
  setuid helper under `/lib/oath` (not PAM, not a pkg). Auto-update
  still cannot write the store: the updater does not sudo. Apply is
  `sudo oath apply`.
- **`host:local.env`.** Map of `NAME=value`. Catalog is truth. PID 1
  injects it into every `svc` spawn (this is how Grok gets
  `GROK_DISABLE_AUTOUPDATER`). `/etc/profile` is a **root-owned**
  side effect for login shells. Do not write `/home/.profile` — the
  seat can edit that. Seed `GROK_DISABLE_AUTOUPDATER=1`. No new kind.
- **No `/usr`.** Helpers live at `/lib/oath/` (`init`,
  `serial-login`, `udhcpc.script`, `run-compositor`, `river-boot`,
  `display-env.sh`, `sudo`). `/sbin/init` → `/lib/oath/init`. PID 1
  is still not a package.
