# Base packages as catalog objects

Extends [2026-08-28-packages.md](2026-08-28-packages.md). Same store,
same `/bin` symlink farm, same verbs. Adds the three files that already
lived in `/bin`.

---

## Locks this freeze owns

- Objects **`pkg:busybox`**, **`pkg:btrfs`**, **`pkg:oath`**, plus the
  existing canary **`pkg:hello`**.
- Each has a store tree `/oath/store/pkg/<name>/`. `/bin/<file>` is a
  symlink into that tree. Busybox **applets** live in the busybox store
  as symlinks to `busybox` (one package, not 395).
- **`actual.removable`**: `false` for busybox, btrfs, `oath`; `true`
  for hello. Engine-owned (like `links`), not a desired field.
- **`present=false` is refused** when `removable` is false — at `set`
  and at `apply`. Not confirm-class. Hint `oath schema pkg`.
- Seed: busybox / btrfs / `oath` are `present: true`. hello stays
  `present: false` until applied.
- PID 1 / `serial-login` stay at `/usr/lib/oath/`. Not packages.
- Still no fetch, no extra names, no `wants`.
