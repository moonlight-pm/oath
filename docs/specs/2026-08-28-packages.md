# Packages as catalog objects

Extends [2026-08-27-catalog-and-oath-surface.md](2026-08-27-catalog-and-oath-surface.md).
Does not replace it. Same verbs, same apply/undo, same btrfs generations.

A package that cannot ship a schema is second-class. There is no `apt`,
no `oath install`, no parallel store UI. `pkg:*` objects are the
package manager.

---

## Locks this freeze owns

- New kind **`pkg`**. Identity `pkg:<name>` (T2).
- v0 object: **`pkg:hello`** only. Do not wrap busybox, btrfs, or `oath`
  in this slice. Do not add other packages.
- **No new verbs.** Install is `oath set pkg:hello present=true` then
  `oath apply`. Remove is `present=false` then apply.
- Bits live under **`/oath/store/pkg/<name>/`**, one directory per
  package. That tree is this package only — not mixed into `/usr`.
- **`/bin` is a symlink farm**, not an unpack target. Apply creates
  symlinks from `/bin/<file>` to the store. No hard links. No second
  PATH (`/oath/store/.../bin` is not on PATH).
- Store is on the live `@` subvolume (under `/oath`) so generations
  cover it. Undo restores catalog documents **including `store/`**,
  then **converges `pkg:*`** (links are a side effect, like hostname).
  Undo does not replace `/oath/run`.
- v0 apply **does not fetch**. The hello payload is packed into the
  image. No network, no glibc runtime, no from-source world.
- Safety: `mutate`.
- `svc` `wants` ordering is **out** of this freeze.

---

## Courage test (definition of done)

On the QEMU appliance, an agent that has never seen Oath:

1. Reads `/oath/INDEX.md`. Sees kind `pkg`.
2. `oath schema pkg` · `oath ls --kind pkg` · `oath get pkg:hello`
3. `oath set pkg:hello present=true` · `oath diff` · `oath apply`
4. `/bin/hello` exists, is a **symlink** into `/oath/store/pkg/hello/`,
   and running it prints `hello`.
5. Reboots. `/bin/hello` still works. `oath get pkg:hello` actual
   `present` is true.
6. `oath set pkg:hello present=false` · `oath apply` — `/bin/hello` is
   gone; the store tree remains (so re-install needs no fetch).
7. `oath undo` — present is true again, `/bin/hello` works.

If that loop works, packages are objects. A tarball pile without it is
not this freeze.

## Tree

```text
/oath/
  objects/pkg/hello/
    desired.json
    actual.json
    meta.json
  schema/pkg.json
  schema/pkg.md
  store/pkg/hello/
    bin/hello          # the payload; packed into the image
/bin/hello -> /oath/store/pkg/hello/bin/hello    # only when present
```

Agents read objects, not the store. INDEX: do not exec from
`/oath/store`; `/bin` is how you run what is installed.

The compatibility shard (`/bin`) exists to execute. Creating or
removing a symlink there is a **side effect of converging** a `pkg`
object. Do not teach an agent to `ln` or `rm` in `/bin`.

## Kind: `pkg`

**desired / actual (v0):**

```json
{
  "present": true
}
```

**actual also records the link farm this object owns:**

```json
{
  "present": true,
  "links": ["hello"]
}
```

- `present` — if true, each file in that package’s `store/.../bin/`
  is symlinked at `/bin/<basename>` (absolute target under
  `/oath/store/...`). If false, those symlinks are removed.
- `links` — basenames in `/bin` this object created. Apply writes
  this. Undo + converge must match desired again.
- Converge must not remove a `/bin` name it does not own.
- Collision: if `/bin/<name>` exists and is not this object’s symlink,
  apply errors (`status=error`). Do not clobber busybox applets.
- Store layout is the v0 manifest: only `bin/` is linked. No `lib/`,
  no PATH mutation.

Seed: `pkg:hello` with `present: false`. Payload already in the store
at first boot.

`/bin/hello` must print `hello` and a trailing newline (probe anchor).

## Apply and undo

Same engine as the catalog freeze.

1. Snapshot `@` → `@gen-N`.
2. Converge selected `pkg:*`: create or remove **this object’s**
   `/bin` symlinks; refresh actual; leave the store tree in place.
3. Log; regenerate INDEX.

**Undo:** restore `objects`, `schema`, `log`, `INDEX.md`, and
`store/` from that generation, then converge every `pkg:*` from
restored desired (re-link or unlink). Then hostname + `svc` as today.

## Out of this freeze
