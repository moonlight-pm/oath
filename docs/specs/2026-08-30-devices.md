# Devices and the Unix floor

Extends the catalog freeze. `/proc` / `/sys` / `/dev` were already
mounted. This freeze makes **hardware inventory** catalog objects and
finishes the mounts a Unix process expects.

No udev. The agent does not run `lspci` to learn the box.

---

## Locks this freeze owns

- Kind **`dev`**. v0 objects: **`dev:vda`**, **`dev:net0`**,
  **`dev:ttyS0`**. Names are what the guest already uses (after
  `net:net0` rename). Not PCI addresses.
- Desired: `{ "present": true }`. These devices are **not removable**
  (`present=false` refused).
- Actual records `class` (`block` / `net` / `tty`) and `node` (path).
  Engine-owned.
- Converge **probes sysfs / `/dev`**. It does not load modules. Init
  still has a hardcoded module list.
- `net:net0` remains the link config. `dev:net0` is the NIC inventory.
- Unix floor (not catalog objects): tmpfs on **`/tmp`**, **`/dev/shm`**,
  **`/run`**; **cgroup2** on `/sys/fs/cgroup`. `/oath/run` stays on
  disk (generations + init.sock). virtio-rng in QEMU. `/etc/hosts`
  has localhost + hostname (side effect of host converge).

---

## Courage test

1. `mount` shows tmpfs on `/tmp`, `/dev/shm`, `/run`.
2. `/sys/fs/cgroup/cgroup.controllers` exists.
3. `oath ls --kind dev` lists `dev:vda`, `dev:net0`, `dev:ttyS0`.
4. `oath get dev:vda` actual `present` true, `node` `/dev/vda`.
5. `oath set dev:vda present=false` fails.
6. Reboot: the three devices still list as present.
