# Network as a catalog object

Extends [2026-08-27-catalog-and-oath-surface.md](2026-08-27-catalog-and-oath-surface.md).
Same verbs, apply/undo, btrfs generations. Serial stays how the agent
reaches the box.

---

## Locks this freeze owns

- Kind **`net`**. One v0 object: **`net:net0`**.
- QEMU **user** networking + **virtio-net**. No tap, no bridge, no
  hostfwd, no SSH.
- The sole guest NIC is **renamed to `net0`** on converge. The agent
  does not hunt `eth0` / `ens3`.
- **Static** IPv4 in desired. v0 appliance values: `10.0.2.15/24`,
  gateway `10.0.2.2` (QEMU slirp). DHCP is later.
- Safety: `mutate`. Downing the link is not confirm-class (serial
  still works).
- No new verbs. No `dev` kind. No package fetch over the net.
- Boot: PID 1 converges `net:net0` after hostname (no snapshot).
  `oath apply` snapshots, then converges.

---

## Courage test

On QEMU:

1. INDEX lists `net`. `oath get net:net0` shows `up: true` and the
   static address.
2. `ip link` shows `net0`. `ping` the gateway `10.0.2.2` works.
3. `oath set net:net0 up=false` · `oath apply` — ping fails; serial
   still works.
4. `oath undo` — ping works again.
5. Reboot — `net0` still up, ping still works.

## Kind: `net`

**desired / actual (v0):**

```json
{
  "up": true,
  "ipv4": "10.0.2.15/24",
  "gateway": "10.0.2.2"
}
```

- `up` — if true, the link is up with `ipv4` and default route via
  `gateway`. If false, addresses flushed, link down.
- `ipv4` — CIDR. Not DHCP.
- `gateway` — IPv4 default route.

Converge uses `/bin/ip` (busybox). Do not teach `ifconfig` or `dhclient`.
