# Display canary (virtio-gpu)

First graphical slice toward Sola. **Not** a Wayland session, not River,
not sola-kit. Prove the guest has DRM and the host can show a window.

---

## Locks

- QEMU **`virtio-gpu-pci`**. Guest node `/dev/dri/card0`. Catalog
  **`dev:card0`** (`class=drm`). Not removable.
- **`cargo make run` / `up` / `start`**: if `DISPLAY` is set, QEMU
  opens a **gtk** window (`-display gtk`). Probe and `OATH_DISPLAY=none`
  stay `-display none`.
- Serial stays. Kernel console: `console=tty0 console=ttyS0`.
- virtio **keyboard + mouse**. No udev. No seatd. No compositor.
- Modules still hardcoded in init: `virtio_dma_buf`, `virtio-gpu`,
  `virtio_input`.

---

## Courage test

1. `test -c /dev/dri/card0` · `oath get dev:card0` actual present.
2. `cargo make run` with `DISPLAY` shows a QEMU window (fb console).
3. Serial and SSH still work. Probe stays headless and passes.
