# Sola session on Oath (`oath-sola`)

River already holds DRM and input (T21/T22). This freeze is the Sola
session on that compositor — **not** Sola’s process manager, **not**
the NixOS module, **not** a second desktop.

Sola today launches bus, call, the River bridge, shell, and session as
children of `crates/sola`. Oath already has a supervisor. Do not nest
one. The fork exists to make that mapping.

---

## Locks this freeze owns

- **GitHub `moonlight-pm/oath-sola`**, private (Sola is). Submodule
  **`forks/sola`**. Daily-driver [moonlight-pm/Sola](https://github.com/moonlight-pm/Sola)
  stays NixOS. Do not land Oath PID 1 / catalog / musl assumptions on
  that main. Pull from it; do not push Oath-compat there.
- **PID 1 remains the only supervisor.** Do not pack or start
  `crates/sola`. `SOLA_NO_SELF_WATCH=1` on Sola `svc:*` so kit apps do
  not re-exec under our supervisor.
- **Bits:** one **`pkg:sola`** (removable), glibc-linked like River.
  Store `/oath/store/pkg/sola/`; `/bin` symlink farm. Not a new kind.
- **Processes** (PID 1 starts each; `wants` is start order):

  | Id | Exec | `wants` |
  |----|------|---------|
  | `svc:sola-bus` | `/bin/sola-bus` | — |
  | `svc:sola-call` | `/bin/sola-call` | — |
  | `svc:sola-river` | `/bin/sola-river` | `svc:river`, `svc:sola-bus`, `svc:sola-call` |
  | `svc:sola-shell` | `/bin/sola-shell` | those three plus `svc:river` |

  `sola-river` here is the **bridge** (bus ↔ Wayland), not the
  compositor (`pkg:river` / `svc:river`).
- **Attach to PID 1’s River.** The fork must find a live Wayland
  socket under `$XDG_RUNTIME_DIR` (`/run/user/0`). Do not require
  Sola’s process manager to write `sola-wayland`. Logs under
  `/oath/log`. GPU/EGL/Vulkan dispatch uses packed Mesa in
  `pkg:river`, not NixOS `/run/opengl-driver`.
- Do not seed `svc:sola-*` until `/bin/sola-bus` (and siblings) exist.
  Missing exec + `restart=always` is a flap.

## Courage test (this slice)

On the QEMU appliance, with `DISPLAY` so gtk can show the GPU:

1. `oath get pkg:sola` actual present.
2. `oath get svc:sola-bus` · `svc:sola-call` · `svc:sola-river` ·
   `svc:sola-shell` — running. Sockets under `/run/user/0`
   (`sola-bus`, `sola-call`, `wayland-*`).
3. The gtk window is Sola chrome (menubar), not an empty River.
   Serial and SSH still work.
4. Probe stays headless and still passes (pids + sockets; probe must
   not require a host display).
5. `pgrep -x sola` is empty — the nested process manager is not
   running.
