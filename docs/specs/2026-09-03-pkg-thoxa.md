# `pkg:thoxa` as the seat login shell

Sister payload: the Thoxa compiler + session REPL (`../Thoxa`, or
`OATH_THOXA`). Same store shape as `pkg:git` / `pkg:grok`. No new kind.

## Locks this freeze owns

- **`pkg:thoxa` is the install.** Bits live in
  `/oath/store/pkg/thoxa/`. `/bin/thoxa` is the symlink farm (wrapper
  that sets `THOXA_*` then execs `libexec/thoxa`). Removable. glibc
  payload (`pkg:glibc` interpreter + rpath). Not in `pkg:sola`.
- **Product face is bare `thoxa`.** Login / empty argv → session REPL.
  `ssh host cmd` is `thoxa -c cmd`. Do not pack `extras/shell`.
- **`/etc/shells` lists `/bin/sh` and `/bin/thoxa`.** Dropbear rejects
  publickey (and looks like a key failure) if `pw_shell` is not listed.
- **Root and serial stay `/bin/sh`.** Busybox. Break-glass.
- **No guest `cc` on the session path.** REPL and `-c` are libtcc
  in-process. Packed `libthoxa_rt.a`, `std/`, TinyCC `libtcc1`, and C
  headers. `thoxa build` remains host-`cc` (gap).
- **No new kind. No new verbs.** First-party/sister payloads stay
  `pkg:*`.
