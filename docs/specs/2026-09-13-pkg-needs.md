# Package needs (runtime graph, no recipe)

Amends [2026-08-28-packages.md](2026-08-28-packages.md) (no deps),
[2026-08-30-wants-and-fetch.md](2026-08-30-wants-and-fetch.md) (package
deps Out), [2026-09-13-sola-oath.md](2026-09-13-sola-oath.md) (packages
panel). Does not add a recipe language (T32). Same verbs. No new kind.

A pack that cannot run without another pack **says so on the object**.
Agents read `oath get`. Apply refuses a broken graph. sola-oath shows
the tree and stages the cascade so Apply can succeed.

---

## Locks this freeze owns

- **`pkg.needs` is a list of `pkg:*` ids** this pack needs at runtime
  (`pkg:glibc`, or `glibc` — same normalize as `svc.wants`). Empty
  means none. No versions, no ranges, no optional extras, no
  build-depends.
- **Not a recipe.** How you built the tree is still yours. `needs` is
  a catalog fact, like `svc.wants` and `pkg.requires.drm_modifiers`.
- **Apply enforces.** Cycles refuse. `present=true` while a need is
  missing or unknown refuses (hint: set the need present). `present=false`
  while another **present** pack still needs it refuses (hint: set those
  present=false first). Apply does **not** rewrite desired for you.
- **sola-oath stages the cascade.** Toggle off A stages A and every
  present pack that needs A (transitive). Toggle on A stages A and
  every need (transitive). If that would turn off a non-removable pack,
  the toggle is refused in the UI. Click is still mutate Apply.
- **Locked packs stay locked.** `needs` does not make `pkg:glibc`
  removable.
- **No new verbs. No new kind.**

## Courage test

1. `oath schema pkg` documents `needs`. `oath get pkg:steam` desired
   `needs` includes `pkg:mesa`.
2. `oath set pkg:mesa present=false` · `oath apply` refuses while
   `pkg:steam` is present; hint names steam.
3. Set steam (and other present dependents) `present=false`, then mesa;
   apply succeeds.
4. sola-oath: select `pkg:mesa` shows Needs / Used by trees. Toggle mesa
   off stages steam (and gamescope if present). Apply matches catalog.
