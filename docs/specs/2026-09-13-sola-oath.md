# Oath catalog client (`sola-oath`)

The operator on a Sola desk should be able to see and change `pkg:*`
without SSH. `oath` stays the only admin surface. This freeze adds a
kit ELF that is a **JSON client** of those verbs — the same adapter
class as flower Restart / Shut Down (`sudo oath set` / `apply --confirm`).

This is not gnome-software, not `apt`, not a second catalog, and not a
pane inside `sola-settings` (that app is seat config:
Applications / Mail / Calendar).

---

## Locks this freeze owns

- **One more ELF in the one `pkg:sola` blob** (T24 / T36). Store
  `/oath/store/pkg/sola/`; `/bin/sola-oath` via the symlink farm.
  Do not add `pkg:sola-oath`. Do not split the blob. Do not add a
  `svc:*`. `sola-session` launches it (direct spawn).
- **`oath` is the only write path.** The app runs
  `/bin/oath --json ls|get|diff` as `home` and
  `/bin/sudo /bin/oath --json set|apply|undo` as `home` (sudo ALL,
  no password). It does not write `/oath/objects` itself. `--json`
  is the same facts as text. Telemetry (`oath-tel`) is stderr; the
  client must skip non-JSON stdout (btrfs snapshot lines).
- **Click is the owner's confirm** only for `confirm`-class applies
  (not this slice). Package `present` is `mutate`. Do not pass
  `--confirm` for pkg apply. INDEX safety still holds for agents.
- **Packages first.** Courage test is `pkg:*` present toggle, Apply,
  Undo. `host:local.session` and `svc:*` panels are later slices of
  the same ELF, not a second app.
- **Locked packs stay locked.** `pkg:busybox` / `btrfs` / `oath` /
  `dropbear` / `glibc` (`actual.removable=false`): toggle disabled.
  Apply of `present=false` on those is refused by the catalog; the
  UI must not offer it.
- **Oath-compat.** Launcher entry **Oath** (`app_id=sola-oath`) only
  when `/oath/INDEX.md` exists. Do not cherry-pick this crate onto
  `moonlight-pm/Sola`. Dual-mode: if launched off Oath, show that the
  catalog is missing; do not talk NixOS logind.
- **Name.** Binary `/bin/sola-oath`. Launcher label **Oath**. Icon
  `lucide/box`. Not “Settings”, not “Software”.
- **No new verbs. No new kind.** Set is staging; Apply snapshots then
  converges; Undo is the last apply’s generation. Several toggles, one
  Apply, one generation (`oath set` each dirty id, then
  `oath apply pkg:a pkg:b`).

Amends T36 only by adding this ELF to the packing list. T36’s other
names stay as they are.
