# Package description and project page

Amends [2026-08-28-packages.md](2026-08-28-packages.md) and
[2026-09-03-pkg-pack-identity.md](2026-09-03-pkg-pack-identity.md)
(`INDEX.md` stays the pack-tree discriminator). Same verbs. No new
kind. `pkg.url` stays the **fetch** URL (T20). This is not that.

An agent (or sola-oath) should not have to open the store to learn
what a pack is or where its project lives.

## Locks this freeze owns

- **`description`** — short prose (one paragraph). Empty means none.
- **`home`** — HTTPS URL of the source tree or main project page.
  Empty means none. Not `pkg.url` (that fetches bits into the store).
- **Catalog facts.** Seed writes them. Apply copies them to actual.
  Pack `INDEX.md` remains optional store prose for two hashes of one
  name (T32). Do not make INDEX.md the live GUI source.
- **No new verbs. No new kind.** sola-oath shows description in the
  pinned detail and opens `home` with `/bin/xdg-open` (`solactl open`).
