# UTC system clock, display timezone later

The kernel clock, logs, and catalog timestamps stay **Zulu**. A human
timezone is how we *show* a time, or how a helper decides “4am on the
wall,” not how the machine stores time.

This is the usual server rule (UTC in the OS, local in the UI). It
fits Oath: the catalog is truth, agents read JSON, apply logs are
one timeline.

---

## Locks this freeze owns

- **System time is UTC.** Hardware clock and kernel time. `date`
  without `TZ` prints UTC. Do not set `/etc/localtime` as a source of
  truth. Do not put `TZ=` in `host:local.env` — that env is injected
  into every `svc` and would make `date(1)` lie in shells and daemons.
- **Recorded timestamps are RFC3339 with `Z`.** Apply log, `snap:N`
  `time`, backup sidecar, `oath-tel` `ts`. Not offset local.
- **Wall-clock schedules keep TZ inside the helper.** T33
  `backup-daily` at 04:00 US Mountain uses POSIX
  `TZ=MST7MDT,M3.2.0,M11.1.0` in that process only. The rest of the
  box stays UTC. No tzdata required for that rule.
- **Display timezone is `host:local.timezone`.** POSIX TZ string.
  Empty = UTC. Seed is US Mountain `MST7MDT,M3.2.0,M11.1.0`. PID 1
  sets `TZ` on **seat** svcs only. Packed Sola wrappers source
  `/lib/oath/display-env.sh` which exports the same. Not `env`, not
  `/etc/localtime`. SSH/`date` stay UTC.
- **No new kind.** Not `tz`, not a `locale` object.

Canto is not “configured for Mountain” at the OS level. Mountain is
the backup schedule and, later, a display preference.

---

## Why not `TZ=America/Denver` on the box

Setting the system timezone makes every log line, every `snap` time,
and every SSH `date` a DST-shifted local time. Agents then have to
guess. Two machines in two zones cannot merge apply logs. Aviation
and almost every serious server keep UTC and translate at the edge.

`host:local.env` is the wrong place: it is process environment, not
a UI setting.

---

## Courage test (when display field exists)

1. `date -u` and `date` agree (both UTC) with `TZ` unset.
2. Catalog and `/oath/log` timestamps end in `Z`.
3. `backup-daily` still fires at 04:00 Mountain with system UTC.
4. A display field, once shipped, changes how a clock is *shown*,
   not `date` or the sidecar.
