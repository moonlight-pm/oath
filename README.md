# Oath

A new Linux distribution. Linux kernel, own userspace. Principles:
**Independence**, **simplicity**, **openness**, **courage**.

Administration is designed for an **AI agent**. The running system has to
explain itself — there will be no training data for a novel OS.

This repository is the product and the engineering record. Nothing boots
yet.
